# Mahjong tile attribution

Tile faces are intended to come from Wikimedia Commons, category
`SVG Planar illustrations of Mahjong tiles`. Individual files may have
different licences: preserve and check each file's attribution and licence.
This document does not claim the set has one licence. Retrieval date is unknown
because the SVG files have not yet been added.
